# Unlock Quality UI

This is a *Factorio* mod that unlocks the quality UI even before researching quality modules. This can be toggled at runtime up until you research quality normally, at which point the quality UI is permanently enabled as usual.

Note that this is implemented by adding a completely hidden and unused quality prototype. Since quality prototypes are limited to a total of 255 instances, this cannot be used with extreme quality mods that already use up all 255 instances.
